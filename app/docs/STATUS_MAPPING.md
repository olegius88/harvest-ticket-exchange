# Статусы талонов

Система управления талонами комбайнера использует следующие статусы для отслеживания жизненного цикла талона:

## Основные статусы

| Статус | Отображение | Описание |
|--------|-------------|----------|
| `created` | **Создан** | Талон создан комбайнером, но еще не назначен водителю |
| `assigned` | **Назначен** | Талон назначен водителю |
| `in_progress` | **В процессе** | Талон находится в процессе выполнения |
| `voditel_signed` | **Подписан водителем** | Водитель подписал талон |
| `completed` | **Завершен** | Талон полностью выполнен |

## Статусы отмены

| Статус | Отображение | Описание |
|--------|-------------|----------|
| `cancelled` | **Отменен** | Талон отменен (общий статус) |
| `cancelled_by_kombainer` | **Отменен комбайнером** | Талон отменен комбайнером |
| `cancelled_by_voditel` | **Отменен водителем** | Талон отменен водителем |

## Цветовая кодировка

- 🔵 **Синий** (`#2196F3`) - Создан
- 🟠 **Оранжевый** (`#FF9800`) - Назначен
- 🟣 **Фиолетовый** (`#9C27B0`) - В процессе
- 🟢 **Зеленый** (`#4CAF50`) - Подписан водителем, Завершен
- 🔴 **Красный** (`#F44336`) - Все статусы отмены

## Использование в коде

### Импорт утилит
```typescript
import { getReadableStatus, getStatusColor } from '../utils/statusUtils';
```

### Использование компонента StatusBadge
```tsx
import { StatusBadge } from '../components/StatusBadge';

// Простое отображение статуса
<StatusBadge status="voditel_signed" />

// С фоном
<StatusBadge status="completed" showBackground={true} />

// С кастомными стилями
<StatusBadge
  status="cancelled"
  textStyle={{ fontSize: 16 }}
  style={{ marginTop: 10 }}
/>
```

### Прямое использование утилит
```tsx
const readableStatus = getReadableStatus('voditel_signed'); // "Подписан водителем"
const statusColor = getStatusColor('completed'); // "#4CAF50"
```
