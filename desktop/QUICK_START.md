# Быстрый старт: Модуль Весовщика

## 🚀 Запуск

1. Откройте PowerShell/командную строку
2. Перейдите в папку: `cd "desktop\Flying Carpet\src-tauri"`
3. Запустите: `cargo tauri dev`
4. В открывшемся окне нажмите кнопку **"Весовщик"**

## 👤 Первый запуск

1. Нажмите **"Регистрация"**
2. Заполните форму:
   - **ФИО**: Ваше полное имя
   - **Телефон**: +7XXXXXXXXXX
   - **Пароль**: минимум 6 символов
3. Нажмите **"Зарегистрироваться"**
4. Автоматический вход в систему

## 📡 Создание точки доступа

1. После входа нажмите **"Создать точку доступа"**
2. Появится QR-код и данные сети
3. Комбайнеры смогут подключиться к вашей сети

## 📱 Подключение мобильных устройств

Мобильные устройства должны:
1. Открыть приложение TalonKombaineraV3 на Android
2. Отсканировать QR-код или ввести данные сети вручную
3. Подключиться к WiFi сети весовщика
4. Отправить данные талонов

## ✅ Готово!

Модуль Весовщика полностью настроен и готов к работе с мобильными устройствами.

**База данных**: автоматически создается в `%APPDATA%/TalonKombaineraV3/`
