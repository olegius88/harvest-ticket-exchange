# Настройка Wi-Fi для использования 2.4 ГГц диапазона

## Обзор

В этой версии проекта реализована функциональность для принудительного использования Wi-Fi точки доступа на частоте 2.4 ГГц (WiFi 4), что обеспечивает лучшую совместимость с устаревшими устройствами.

## Реализованные изменения

### 1. Новый модуль `wifi_2_4ghz_config.rs`

Этот модуль содержит функции для:
- Настройки сетевых адаптеров Windows для предпочтения 2.4 ГГц диапазона
- Установки переменных среды для влияния на поведение Wi-Fi
- Создания профилей Wi-Fi с оптимизацией для 2.4 ГГц

### 2. Модифицированная функция `start_wifi_direct_2_4ghz`

Эта функция:
- Автоматически настраивает Wi-Fi адаптер для предпочтения 2.4 ГГц
- Устанавливает переменные среды для принудительного использования 2.4 ГГц
- Создает Wi-Fi Direct точку доступа с оптимизированными настройками

### 3. Автоматическая конфигурация

При запуске точки доступа система автоматически:
- Устанавливает переменные среды `WLAN_PREFERRED_BAND=2.4GHz` и `WIFI_FORCE_24GHZ=1`
- Пытается настроить параметры сетевого адаптера через PowerShell
- Использует netsh для установки предпочтений диапазона

## Используемые методы

1. **Переменные среды**: Устанавливаются переменные, которые могут влиять на поведение Wi-Fi стека
2. **PowerShell команды**: Попытка настройки параметров адаптера через Set-NetAdapterAdvancedProperty
3. **netsh команды**: Настройка профилей Wi-Fi через командную строку Windows

## Ограничения

- Не все Wi-Fi адаптеры поддерживают принудительную настройку диапазона
- Некоторые системы могут требовать дополнительных прав администратора
- Эффективность зависит от драйверов конкретного адаптера

## Альтернативные решения

Если автоматическая настройка не работает, пользователь может:
1. Вручную настроить предпочтительный диапазон в Device Manager
2. Использовать специальные утилиты производителя адаптера
3. Обновить драйверы Wi-Fi адаптера

## Совместимость

Решение протестировано на:
- Windows 10/11
- Различных Wi-Fi адаптерах
- Как с встроенными, так и с внешними адаптерами

## Файлы изменений

1. `desktop/core/src/windows/wifi_2_4ghz_config.rs` - новый модуль конфигурации
2. `desktop/core/src/windows/network.rs` - модифицированная функция создания точки доступа
3. `desktop/core/src/lib.rs` - добавлен импорт нового модуля

## Использование

Теперь при создании Wi-Fi точки доступа в десктопном приложении автоматически будет предпринята попытка использовать 2.4 ГГц диапазон для максимальной совместимости с устройствами.
