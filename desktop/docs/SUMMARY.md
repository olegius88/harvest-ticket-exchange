## 🚀 Как использовать

### Запуск приложения
1. Откройте терминал в `desktop/Flying Carpet/src-tauri/`
2. Выполните: `cargo tauri dev`
3. В открывшемся окне нажмите "Весовщик"

### Первый запуск
1. Нажмите "Регистрация"
2. Заполните форму (ФИО, телефон, пароль)
3. Автоматический вход после регистрации

### Создание точки доступа
1. Войдите в систему
2. Нажмите "Создать точку доступа"
3. Получите QR-код для подключения Android устройств
