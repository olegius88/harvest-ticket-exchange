# Весовщик модуль - TalonKombaineraV3 Desktop

## Обзор

Модуль Весовщика в TalonKombaineraV3 Desktop представляет собой полноценную систему для:
- Авторизации и регистрации весовщиков
- Создания WiFi точки доступа для приема данных от комбайнеров
- Интеграции с основной системой управления талонами

## Компоненты системы

### 1. База данных SQLite
- **Расположение**: `%APPDATA%/TalonKombaineraV3/talon_kombainera.db`
- **Таблицы**: `users` (пользователи системы)
- **Безопасность**: Пароли хешируются с использованием bcrypt

### 2. Веб-интерфейс
- **Главная страница**: `vesovschik.html` - интерфейс для весовщиков
- **JavaScript**: `vesovschik.js` - логика взаимодействия с бэкендом
- **Стили**: Bootstrap 5 для современного UI

### 3. Rust Backend (Tauri)
- **Команды**:
  - `register_vesovschik` - регистрация нового весовщика
  - `login_vesovschik` - авторизация весовщика
  - `validate_vesovschik_session` - проверка сессии
  - `start_vesovschik_hotspot` - создание точки доступа
  - `stop_vesovschik_hotspot` - остановка точки доступа

## Использование

### Запуск приложения
1. Откройте терминал в папке `desktop/Flying Carpet/src-tauri/`
2. Выполните команду: `cargo tauri dev`
3. В открывшемся окне выберите кнопку "Весовщик"

### Первый запуск (регистрация)
1. Нажмите кнопку "Весовщик" на главном экране
2. Нажмите кнопку "Регистрация"
3. Заполните форму:
   - **ФИО**: Полное имя весовщика
   - **Номер телефона**: В формате +7XXXXXXXXXX
   - **Пароль**: Минимум 6 символов
   - **Подтверждение пароля**: Должно совпадать с паролем
4. Нажмите "Зарегистрироваться"
5. После успешной регистрации автоматически произойдет вход в систему

### Вход в систему
1. Нажмите кнопку "Весовщик" на главном экране
2. Нажмите кнопку "Вход в систему"
3. Введите номер телефона и пароль
4. Нажмите "Войти"

### Работа с талонами
1. После входа в систему нажмите "Создать точку доступа"
2. Будет создана WiFi сеть с автоматически сгенерированными параметрами
3. На экране отобразится:
   - Название сети (SSID)
   - Пароль для подключения
   - QR-код для быстрого подключения с мобильных устройств
4. Комбайнеры смогут подключиться к этой сети и передать данные талонов

## Технические детали

### Безопасность
- Пароли хешируются с использованием bcrypt (cost 12)
- Валидация номеров телефонов по regex
- Проверка прав доступа по роли пользователя
- Защита от SQL-инъекций через параметризованные запросы

### База данных
**Таблица users:**
```sql
CREATE TABLE users (
    id TEXT PRIMARY KEY,           -- UUID пользователя
    fio TEXT NOT NULL,            -- ФИО
    phone TEXT NOT NULL UNIQUE,   -- Номер телефона (уникальный)
    position TEXT NOT NULL,       -- Должность ("vesovschik")
    password_hash TEXT NOT NULL,  -- Хеш пароля
    created_at TEXT NOT NULL,     -- Время создания
    updated_at TEXT NOT NULL,     -- Время обновления
    from_remote BOOLEAN NOT NULL  -- Флаг удаленного создания
);
```

### API команды Tauri

#### `register_vesovschik(CreateUserRequest) -> Result<String, String>`
Регистрирует нового весовщика в системе.

#### `login_vesovschik(LoginRequest) -> Result<SafeUser, String>`
Выполняет авторизацию весовщика по телефону и паролю.

#### `validate_vesovschik_session(user_id: String) -> Result<bool, String>`
Проверяет валидность сессии пользователя.

#### `start_vesovschik_hotspot(user_id: String) -> Result<HotspotInfo, String>`
Создает WiFi точку доступа для приема данных от комбайнеров.

#### `stop_vesovschik_hotspot() -> Result<String, String>`
Останавливает работающую точку доступа.

## Интеграция с Android приложением

- Генерирует QR-коды в совместимом формате
- Создает WiFi сети с совместимыми параметрами

## Устранение неполадок

### База данных не создается
- Проверьте права доступа к папке `%APPDATA%`
- Убедитесь, что SQLite библиотека скомпилирована корректно

### Ошибки компиляции
- Убедитесь, что установлены все зависимости Rust
- Проверьте версию Tauri (требуется v2.0+)

### Проблемы с WiFi
- В текущей версии hotspot создается в симулированном режиме
- Для реальной работы с WiFi требуется интеграция с системными API
