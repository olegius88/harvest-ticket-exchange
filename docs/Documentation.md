## 1. Техническая документация

Этот раздел предназначен для разработчиков, которые будут поддерживать и дорабатывать проект.

### 1.1. Обзор проекта

**"Талон Комбайнера v3"** — это мобильная система для цифровизации процесса учета и передачи талонов (учетных листов) между комбайнерами и водителями во время уборочных работ.

**Основная цель** — заменить бумажные талоны на электронные и обеспечить их надежную передачу в условиях отсутствия стабильного интернет-соединения.

**Ключевая особенность архитектуры** — система работает в режиме **peer-to-peer (P2P)** в локальной сети Wi-Fi. Одно из устройств (комбайнер) выступает в роли сервера (создавая точку доступа), а другое (водитель) — в роли клиента. Это позволяет обмениваться данными напрямую между устройствами без зависимости от внешнего бэкенда или интернета.

### 1.2. Технологический стек

*   **Платформа:** React Native 0.80
*   **Язык:** TypeScript
*   **База данных:** WatermelonDB (`@nozbe/watermelondb`) — высокопроизводительная реактивная СУБД, работающая поверх SQLite. Обеспечивает локальное хранение данных и сложную логику запросов.
*   **Навигация:** React Navigation (`@react-navigation/native-stack`)
*   **Сетевое взаимодействие:** `react-native-tcp-socket` — библиотека для создания низкоуровневых TCP-клиентов и серверов. Является ядром P2P-взаимодействия.
*   **Работа с QR-кодами:**
    *   `react-native-vision-camera`: Доступ к камере для сканирования.
    *   `react-native-qrcode-svg`: Генерация и отображение QR-кодов.
*   **Управление состоянием:** Неявное, через реактивность WatermelonDB и контекст React.
*   **Инструменты:**
    *   ESLint, Prettier — для контроля качества и стиля кода.
    *   `env-cmd` — для управления переменными окружения (`.env.dev`, `.env.dev.nout`).

### 1.3. Архитектура и структура проекта

#### 1.3.1. Корневая структура

- **`/app`**: Исходный код мобильного приложения React Native.
- **`/docs`**: Дополнительная документация и медиафайлы.
- **`package.json`**: Основной файл проекта, управляет общими зависимостями и скриптами.

#### 1.3.2. Структура мобильного приложения (`/app`)

- **`/android`, `/ios`**: Платформенный код для Android и iOS.
- **`/db`**: Определения моделей и схемы для WatermelonDB.
    - `database.ts`: Инициализация БД.
    - `migrations.ts`: Миграции схемы данных.
    - `users.ts`, `kombainers.ts`, `voditeli.ts`, `talons_of_combainers.ts`: Модели таблиц.
- **`/pages`**: Экраны приложения, сгруппированные по ролям.
    - `Login.tsx`, `Registration.tsx`, `Main.tsx`: Общие экраны.
    - `/kombainer`: Экраны для роли "Комбайнер".
    - `/voditel`: Экраны для роли "Водитель".
- **`/services`**: Высокоуровневые сервисы.
    - `ConnectionManager.ts`: Управляет жизненным циклом сетевых соединений (запуск, штатное и экстренное завершение).
    - `MessageHandler.ts`: Обрабатывает входящие TCP-сообщения.
- **`/wifi`**: Низкоуровневая реализация сетевого стека.
    - `TcpServer.ts`: Реализация TCP-сервера, который запускается на устройстве комбайнера.
    - `TcpClient.ts`: Реализация TCP-клиента для устройства водителя.
    - `onTcpMessage.ts`: Логика-маршрутизатор для обработки различных типов сообщений.
- **`/components`**: Общие переиспользуемые UI-компоненты (например, `StatusBadge.tsx`).
- **`/hooks`**: Пользовательские хуки React.
- **`App.tsx`**: Корневой компонент приложения, где настраивается навигация.

### 1.4. Ключевые модули и логика

#### 1.4.1. Роли пользователей

Система имеет две основные роли:
1.  **Комбайнер**: Основной пользователь, который создает талоны. Его устройство выступает в роли **сервера**: создает точку доступа Wi-Fi и запускает TCP-сервер.
2.  **Водитель**: Принимает талоны от комбайнера. Его устройство — **клиент**, который подключается к Wi-Fi комбайнера и устанавливает TCP-соединение.

#### 1.4.2. Процесс передачи талона (основной сценарий)

1.  **Инициация (Комбайнер)**:
    *   Комбайнер активирует режим "Передача талона".
    *   Приложение программно включает точку доступа Wi-Fi на устройстве.
    *   Запускается TCP-сервер на заранее определенном или случайном порту (`TcpServer.ts`).
    *   На экране генерируется QR-код, содержащий информацию для подключения (SSID и пароль от Wi-Fi, IP-адрес и порт сервера).

2.  **Подключение (Водитель)**:
    *   Водитель открывает на своем устройстве сканер QR-кодов.
    *   Приложение сканирует QR-код с экрана комбайнера.
    *   Получив данные, приложение автоматически подключается к указанной сети Wi-Fi.
    *   Устанавливается TCP-соединение с сервером комбайнера (`TcpClient.ts`).

3.  **Обмен данными**:
    *   После установки соединения приложения обмениваются JSON-сообщениями. Протокол обмена определен в `onTcpMessage.ts`. Каждое JSON-сообщение завершается символом `
` для корректной буферизации.
    *   Комбайнер отправляет данные о талоне.
    *   Водитель получает данные, сохраняет их в свою локальную БД WatermelonDB и отправляет подтверждение.

4.  **Завершение**:
    *   После успешного обмена данными или по истечении тайм-аута соединения разрываются.
    *   `ConnectionManager.ts` предоставляет функции для штатного (`graceful`) и принудительного разрыва соединений.
    *   Точка доступа на устройстве комбайнера отключается.

### 1.5. Установка и запуск

#### 1.5.1. Настройка окружения

1.  **Установите Node.js**: Требуется версия 18 или выше.
2.  **Установите Java Development Kit (JDK)**: Рекомендуется версия 11 (Zulu).
3.  **Настройте Android SDK**: Установите Android Studio и настройте переменные окружения (`ANDROID_HOME`).
4.  **Установите Watchman** (рекомендуется для macOS/Linux для лучшей производительности Metro).

#### 1.5.2. Установка зависимостей

```bash
# Установка зависимостей для корневого проекта (утилиты)
npm install

# Переход в директорию мобильного приложения и установка его зависимостей
cd app
npm install
```

#### 1.5.3. Запуск мобильного приложения

Все команды для запуска выполняются из директории `/app`.

1.  **Запуск Metro Bundler:**
    ```bash
    # Для разработки (с переменными из .env.dev)
    npm run start:dev

    # Для разработки на ноутбуке (с переменными из .env.dev.nout)
    npm run start:dev:nout
    ```

2.  **Запуск на Android:**
    *   Убедитесь, что у вас подключено устройство или запущен эмулятор.
    *   В новом терминале выполните:
    ```bash
    cd app
    npm run android
    ```

#### 1.5.4. Сборка Android-приложения (APK)

Команды выполняются из директории `/app`.

-   **Собрать Release APK:**
    ```bash
    npm run build:android:win
    ```
-   **Увеличить версию и собрать Release APK:**
    ```bash
    npm run build:android:inc-ver:win
    ```
    Собранный `.apk` файл будет находиться в `app/android/app/build/outputs/apk/release/`.

## 2. Пользовательская документация

Этот раздел предназначен для конечных пользователей приложения: комбайнеров и водителей.

### 2.1. Введение

Приложение **"Талон Комбайнера"** позволяет отказаться от бумажных талонов и вести их учет в электронном виде прямо на вашем мобильном устройстве. Система работает без интернета, обеспечивая прямую связь между комбайнером и водителем.

### 2.2. Начало работы

#### 2.2.1. Установка
-   **Android**: Установите приложение из предоставленного `.apk` файла.
-   **iOS**: Инструкции по установке для iOS будут предоставлены дополнительно.

#### 2.2.2. Регистрация и вход
1.  При первом запуске приложения откройте экран **"Регистрация"**.
2.  Выберите вашу роль: **"Комбайнер"** или **"Водитель"**.
3.  Заполните необходимые данные (имя, логин, пароль).
4.  После успешной регистрации вернитесь на главный экран и используйте свой логин и пароль для **входа** в систему.

### 2.3. Основные функции (Комбайнер)

#### 2.3.1. Создание талона
1.  На главном экране нажмите кнопку **"Создать талон"**.
2.  Заполните информацию о талоне: номер поля, культура и т.д.
3.  Нажмите **"Сохранить"**. Талон появится в вашем списке со статусом "Новый".

#### 2.3.2. Передача талона водителю
1.  В списке ваших талонов выберите тот, который хотите передать.
2.  Нажмите кнопку **"Сгенерировать QR-код для передачи"**.
3.  На экране появится QR-код. **Водитель должен отсканировать этот код своим устройством.**
4.  Во время сканирования ваше устройство создаст временную Wi-Fi сеть для безопасной передачи данных.
5.  После того как водитель успешно примет талон, его статус изменится на "Передан водителю".

### 2.4. Основные функции (Водитель)

#### 2.4.1. Прием талона от комбайнера
1.  На главном экране нажмите кнопку **"Сканировать QR-код"**.
2.  Наведите камеру на QR-код, который показывает комбайнер.
3.  Приложение автоматически подключится к устройству комбайнера и примет талон.
4.  После успешного приема талон появится в вашем списке.

#### 2.4.2. Работа с принятым талоном
1.  Вы можете просматривать список принятых талонов.
2.  После взвешивания груза вы можете указать вес в деталях талона и изменить его статус (например, на "Вес указан" или "Сдан на склад").

### 2.5. Решение проблем

-   **Не удается отсканировать QR-код**: Убедитесь, что камера чистая, а на экране комбайнера достаточная яркость. Попробуйте поднести камеру ближе или дальше от кода.
-   **Ошибка подключения**: Убедитесь, что на обоих устройствах включен Wi-Fi. Перезапустите процесс генерации QR-кода на устройстве комбайнера и попробуйте снова.
